# 🌾 PbaSistem - Sistema de Gestión para Productos Biológicos Agrícolas

Aplicación empresarial desarrollada para optimizar el control de ventas, compras e inventario de una empresa distribuidora de insumos biológicos para la agricultura.

## 📌 Contexto del Proyecto
- **Tipo:** Proyecto Académico / Caso Real (Taller de Programación I).
- **Equipo:** 4 integrantes.
- **Calificación obtenida:** 18/20.
- **Problema que resuelve:** Automatización y seguimiento de la compra de insumos, historial de ventas, gestión de proveedores y control de flujo de caja en un sector agrícola especializado.

## 🛠️ Tecnologías Utilizadas
- **Lenguaje:** Java
- **Framework:** OpenXava (Arquitectura basada en componentes de negocio)
- **Gestor de dependencias:** Apache Maven
- **IDE:** NetBeans

## 👨‍💻 Mi Rol y Aportes
**Rol:** Líder de Proyecto y Desarrollador
- Diseño e implementación del módulo de **Autenticación / Login**.
- Desarrollo del **Flujo de caja** para el registro y balance de ventas de productos.
- Gestión y coordinación del equipo de desarrollo.
